## 📌 About the Project

**NITRR Volleyball League** is a web-based registration platform created to simplify the process of registering teams and players for volleyball league matches at **National Institute of Technology, Raipur**.

The project was built as a complete web development project, from designing the interface to implementing the registration flow and deploying the website.

The goal was simple:

**Make volleyball league registration easier, cleaner, and more accessible for students.**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/samarthkhandelwal1281-cpu/NITRR_volleyball_league.git
```

### 2. Navigate to the project

```bash
cd NITRR_volleyball_league
```

### 3. Run the project

Since this is a static website, you can simply open:

```text
Index.html
```

in your browser.

Alternatively, use a local development server such as the **Live Server** extension in VS Code.
